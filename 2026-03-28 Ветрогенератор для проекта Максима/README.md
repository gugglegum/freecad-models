Что уже сделано:
- Логика крестовин и креплений сильно переработана.
- Вместо просто наглядных шайб/лучей теперь есть:
  - `HubRow_*` = отдельные крестовины: центральная шайба + 3 луча
  - `HubMount_*` = отдельные криволинейные седловидные крепления на концах лучей
- Крестовин теперь 3 штуки, по числу рядов седел на лопасти.
- Лучи теперь точно попадают в места крепления.

Текущая конструкция:
- Луч входит в прямоугольный паз в отдельном седле `HubMount`.
- Это именно вдавленный внутрь паз, а не наружный выступ.
- Посадочный зазор: `ARM_SOCKET_CLEARANCE = 0.2` мм с каждой стороны.
- Глубина захода луча в паз: `ARM_TAB_DEPTH = 2.5` мм.
- Небольшой зазор на дне паза: `ARM_SOCKET_END_GAP = 0.2` мм.
- Толщина отдельного седловидного крепления: `MOUNT_THICK = 7.5` мм.

Отверстия и крепеж:
- На седлах лопастей остаются отверстия под вплавляемые латунные гайки M3.
- На отдельном седле `HubMount` боковые отверстия к лопасти сделаны двухступенчатыми:
  - сквозная часть: `MOUNT_HOLE_CLEAR_DIAMETER = 3.5`
  - расточка под головку: `MOUNT_HOLE_HEAD_DIAMETER = 6.5`
  - глубина расточки: `MOUNT_HOLE_HEAD_DEPTH = 3.5`
- В центре `HubMount` тоже есть двухступенчатое отверстие под винт, которым седло стягивается с лучом.
- На торце луча есть круглый карман под латунную вставку:
  - `INSERT_HOLE_DIAMETER = 4.6`
  - `INSERT_HOLE_DEPTH = 2.8`

Ключевая сложная проблема, которую уже решили:
- В прямоугольном пазе отдельного седла `HubMount` были два маленьких “висящих” артефакта поверхности/тела.
- Много попыток исправить это порядком булевых операций не помогли.
- Потом была сделана headless-диагностика через `freecadcmd`, и выяснилось, что проблема не в лицах, а в том, что `HubMount_2_1` состоял из 3 solid'ов:
  - 1 нормальный solid
  - 2 микроскопических паразитных solid'а
- После этого в код была добавлена функция:
  - `keep_largest_solid(shape)`
- Она оставляет только самый большой solid и отбрасывает мелкие паразитные осколки.
- Сейчас она применяется в `make_mount_solid()` после центрального выреза и после `removeSplitter()`.
- После этого артефакт исчез.
- Проверка headless показывала `Solids: 1`.
